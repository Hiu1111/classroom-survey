# AI-Assisted Development Summary

## Project: Classroom Survey Web App

**Course:** CSE 4095 — Agentic Programming  
**Date:** November 5, 2026

## Overview

During the development of the Classroom Survey Web App, I used AI-assisted programming tools, including Cursor and ChatGPT, to help plan, implement, troubleshoot, and document the application.

AI tools were used throughout the development process to support coding and problem-solving. I worked through the project incrementally, integrating the generated code into my local development environment and testing the application as features were added.

## How AI Was Used

### Project Setup and Frontend Development

AI assistance helped establish the React, TypeScript, and Vite project structure. It also supported the development of the instructor dashboard, survey editor, student survey page, QR-code presentation page, and results dashboard.

### Database and Backend Integration

AI tools assisted with designing the Supabase database schema, configuring relationships between tables, implementing database functions, and connecting the frontend to Supabase.

This included instructor authentication, survey activation, anonymous response submission, and database access controls.

### Debugging and Troubleshooting

AI assistance was used to investigate TypeScript build errors, Supabase database permission issues, and deployment configuration problems.

I tested suggested solutions in my development environment and verified that the application worked before continuing.

### Testing and Deployment

AI tools helped guide the testing process and the deployment of the application using GitHub and Cloudflare Pages.

I verified the main application workflow, including instructor login, survey creation, student participation, and results visualization.

### Documentation

AI assistance was also used to organize and prepare the README, database migration documentation, development summary, and project progress checklist.

## Reflection

Using AI tools helped make the development process more efficient, especially when working with unfamiliar technologies and troubleshooting integration issues.

However, the generated code and recommendations still needed to be configured, tested, and verified. This project demonstrated the importance of reviewing AI-assisted work rather than assuming that generated solutions will function correctly without testing.

The final application combines AI-assisted development with hands-on configuration, debugging, testing, and deployment.

## Limitations

The project was tested using its primary application workflows, but comprehensive load testing and additional security testing were not completed. Some code-quality issues remain unresolved.
